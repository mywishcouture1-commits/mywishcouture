# My Wish by Mahwish Rabbani — Website

This folder is your whole website. Here's how to get it online for free using GitHub Pages.

## Step 1: Create a GitHub account
Go to github.com and sign up (free).

## Step 2: Create a new repository
1. Click the **+** in the top right → **New repository**
2. Name it something like `my-wish-website`
3. Set it to **Public**
4. Click **Create repository**

## Step 3: Upload these files
1. On your new repository's page, click **Add file** → **Upload files**
2. Upload every file and folder from this project (index.html, shop.html, about.html, contact.html, the `css` folder, and the `images` folder)
3. Scroll down, click **Commit changes**

## Step 4: Turn on GitHub Pages
1. In your repository, click **Settings** (top menu)
2. Click **Pages** (left sidebar)
3. Under "Branch," choose **main**, and folder **/ (root)**
4. Click **Save**
5. Wait about 1–2 minutes, then refresh — GitHub will show you your live link, something like:
   `https://yourusername.github.io/my-wish-website/`

That link is your live website. Share it anywhere — Facebook, Instagram bio, text messages.

## Step 5: Fill in the placeholders
See **PLACEHOLDERS-TO-FILL-IN.md** for a checklist of everything that still needs real info (Snipcart key, Formspree link, social media links, YouTube video, product photos and final prices).

## Adding or editing products later
See **PRODUCT-TEMPLATE.txt** for a copy-paste block to add a new product to shop.html, and instructions for editing prices in Snipcart's dashboard.

## Using a custom domain (optional)
If you want something like `mywishclothing.com` instead of the github.io link:
1. Buy the domain from a site like Namecheap or GoDaddy (~$10–15/year)
2. In GitHub, go to Settings → Pages → add your custom domain there
3. Follow GitHub's on-screen instructions to point your domain to it (this involves adding a couple of DNS records at wherever you bought the domain — GitHub's Pages settings page walks you through exactly what to enter)
