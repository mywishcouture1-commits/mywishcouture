# My Wish Couture — Website

Files: index.html, shop.html, services.html, about.html, contact.html, style.css,
plus these guides. All files stay in ONE folder (no subfolders) so phone uploads work.

To update anything later: upload a file with the SAME name and it replaces the old one.
To delete a file on GitHub: open it, tap the three dots (...), tap Delete file, then Commit changes.

Turn on the live site: Settings > Pages > Branch: main, / (root) > Save.
